# Contributing to stuAtt

**stuAtt — Student Attendance Management System**.

This project was developed by two team members using Git and GitHub. Contributions should be made through feature branches and pull requests so that changes can be reviewed before being merged into `main`.

## Team and Primary Areas

| Member | Roll No. | Primary development areas |
|---|---:|---|
| Ayser Islam | 17 | Student and attendance database CRUD operations, main teacher web interface and dashboard, attendance marking and updation, student search and updation, attendance filtering, shared navigation and page layouts |
| Shivam Chaudhary | 55 | Teacher login and authentication, admin login, admin dashboard and commands, user account management, attendance analytics and statistics, attendance percentage calculation, defaulter identification and filtering, CSV report generation |

These describe each member's primary areas of responsibility. Both members collaborated on integration, testing, Git branching, pull requests, code reviews and merge-conflict resolution.

## Branching

The project uses these branches:
- `main` — integrated project branch.
- `feature-member1` — Ayser Islam's feature branch.
- `feature-member2` — Shivam Chaudhary's feature branch.

Switch to your assigned branch before making changes:

```bash
git switch feature-member1
```

or

```bash
git switch feature-member2
```
